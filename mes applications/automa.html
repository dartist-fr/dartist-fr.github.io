01 / Le projet

Un accueil à ton image.

Automa explore la personnalisation Android avec des widgets et des réglages visuels pensés pour adapter l’écran d’accueil à ses besoins. Les fonctionnalités évoluent selon les versions publiées.

  • Widgets personnalisablesDes informations utiles directement sur l’écran d’accueil.
  • Réglages visuelsAdapter l’apparence à ses préférences.
  • Versions suiviesRetrouver les nouveautés et les anciennes publications.
  • Projet indépendantConsulter le dépôt et suivre le développement.

02 / Téléchargement

Toujours depuis la source officielle.

Les fichiers APK sont publiés dans les GitHub Releases du projet. Ouvre la dernière version, puis sélectionne le fichier APK dans la section « Assets ». Les notes de version et les publications précédentes restent disponibles sur GitHub.

Conseil : Android peut demander l’autorisation d’installer une application provenant de cette source. Vérifie toujours la version et le fichier téléchargé avant l’installation.
